# 决策规则速查 — 王忠钊：广告创意与 AI 实践

| 能力 | 一句话规则 |
|---|---|
| 先找到卡点再做 AI 试点 | 先验证真实卡点，再用质量、成本和他人采用验收。 |
| 把经验变成脚本生产规则 | 先整理产品事实和标准，打样合格再批量。 |
| 把脚本交给 AI 制作 | 逐镜定义画面、角色、运动和音频，保留人工合成验收。 |
| 让投放结果回到下一条创意 | 先关联脚本、素材、标签和结果，人工核对后再生成变体。 |
| 按用户和产品阶段安排创意 | 先明确吸引谁，再组合开头、卖点和行动引导。 |
| 按效果安排下一批素材 | 跑出率与成本回收一起看，缺口径时先不派具体数量。 |
| 检查雪刀素材是否符合品牌 | 逐项检查标志、颜色、字体和角色应用，冲突项单列待确认。 |
| 按范围完成 CS 审核 | 先筛本人待审，再逐项核验，只批量处理已确认通过的部分。 |
| 把经验变成别人能接手的方法 | 讲清真实试验与边界，让另一个人完成任务检验复用。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
